
# Library App Management System

This is simple web application for library app management system build with Python Fastapi and ReactJs.


## Run Locally

Clone the project

```bash
  git clone https://github.com/rikhoari01/libraryapp-fastapi-react.git
```

Go to the project directory

```bash
  cd libraryapp-fastapi-react
```

### Run API

Go to the project api directory

```bash
  cd library-api
```

Install api depedencies

```bash
  pip install -r requirements.txt
```

Create api env file
```bash
  cp .env.example .env
```

Run api
```bash
  python src/main.py
```

### Run UI

Go to the project ui directory

```bash
  cd library-ui
```

Install ui depedencies

```bash
  npm install
```

Create ui env file
```bash
  cp .env.example .env
```

Run ui
```bash
  npm run dev
```

Copy this link to the browser
```bash
  localhost:5174
```
