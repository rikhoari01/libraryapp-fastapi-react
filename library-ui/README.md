
# Library App Management System UI

This is the UI of Library App Management System


## Run Locally

Clone the project

```bash
  git clone https://github.com/rikhoari01/libraryapp-fastapi-react.git
```

Go to the project directory

```bash
  cd libraryapp-fastapi-react
```

Go to the project ui directory

```bash
  cd library-ui
```

Install ui depedencies

```bash
  npm install
```

Create ui env file
```bash
  cp .env.example .env
```

Run ui
```bash
  npm run dev
```

Copy this link to the browser
```bash
  localhost:5174
```
